# 当期祝福、配队与留人：三份中文转录及 YouTube 补充

日期：2026-09-18。对应 [研究高手如何联动当期祝福、配队与关键角色预留](https://github.com/HaotongCheng/BetterTheater/issues/11)，为 [决定怎样描述角色与队伍的实际可用能力](https://github.com/HaotongCheng/BetterTheater/issues/5) 提供事实依据。本报告不选择推荐算法，也不把作者推荐变成玩家禁选规则。

## 研究结果

应描述的是**某个队伍在当前祝福、配置、敌人和后续预留约束下能承担什么任务**。单独的角色强度、星级、反应标签或祝福总等级均不够。最有用的新证据不是一张更长的角色排名，而是作者在没刷到理想祝福、缺少预期角色、已有后关主力等条件下如何改变选择。

本轮已阅读全文：用户指定的三份 B 站视频字幕，以及一位独立 YouTube 作者的当前期自动字幕。原始三个 Markdown 是 BibiGPT 摘要和章节总结；随后从其分享页取得了完整 SRT，已将摘要与逐段字幕核对。两条用户取消的视频不再列入待办。没有观看、抽帧或下载视频，没有让多模态模型解析画面。

材料足以完成本次定性研究，但**不是完整实战账本或已复现的通关证明**。字幕未说出的候选、报价、剩余花朵、耐力、面板与战后数据仍未知。项目锚点为北美服；这些作者的服务器未由字幕核实，不能称为北美服实测。若要测算成功率、收益或低练门槛，须由后续验证补齐；无需为了完成这张事实研究票假造这些字段。

## 核心案例：推荐路线并不是实际执行路线

以下均为A的连续字幕证据。“实际”限于作者在讲解中明确说出的当时情况，不代表研究者观察了画面。

| 时间 | 条件或偏离 | 作者处理 | 对能力判断的意义 |
|---|---|---|---|
| 03:25–03:53 | 计划招两人、感电升2级左分支；随后明说当时只拿到1级 | 不要求立即刷新，继续演示 | 目标祝福和已购祝福要分开；没达理想路线不等于当前队伍不可用 |
| 05:21–05:45 | 希望有绽放原态；没拿到也允许继续 | 第二幕围绕菈乌玛、行秋、卡维安排 | 推荐增益不总是必要门槛；这也不是“纯四星队”证据 |
| 06:52–07:14 | 第五幕需要水位、第六幕需要主力；想把感电升4级但未拿到 | 提前招需要的人；已有2级也能先开战 | 不能为终态祝福持续花费，忽视眼前招募和后关覆盖 |
| 11:52–12:26 | 条件备选：若未招到预想的水角色，但拿到自有主力 | 可让主力承担第五幕，把菈乌玛留到第九幕；本次口述的第五幕队伍仍使用菈乌玛 | 留人计划可以随入队改变；这里是备选解释，不能声称作者本次已执行该改队 |
| 14:32–14:52 | 招一名角色，再看后续主力所需反应 | 后续祝福按水草或雷草路线补 | 祝福的价值取决于会使用它的人，而非反应全局排名 |
| 19:56–21:06 | 接近后段，需要为圣牌二准备挂草；第九幕可选不同护盾敌人 | 根据水、草储备选更适配的敌人；保留此前省下的角色选项 | 预留应指出未来任务，同时可通过关卡选择降低资源压力 |
| 21:36–22:00 | 最后准备主力与机制应对者 | 人够才继续买祝福，不够先补人 | “够”应由后续可组队与机制覆盖解释，不只是人数阈值 |

这些片段展示了条件链，却没有每步完整花朵和耐力。不能把作者在不同分支说过的所有队伍串成同一条无矛盾轨迹，更不能反推出最优购买顺序或刷新概率。

## 预留的是任务能力，星级只是一项背景

A 00:17–01:38、02:15–03:18把后段任务分开：第六幕的水应用、第八幕的感电体系、圣牌二的持续挂草与合适输出、第十幕的治疗。它明确提到祭礼弓柯莱用于圣牌二，说明武器和循环属于可用能力条件；并允许其他草角色替代，但不声称速度相同。

特别容易被摘要误导的是借角：A 02:15–02:43先判断自己是否已有适合圣牌二的主C。**已有才优先考虑借那维莱特；没有则先补这个空缺。** 作者对奈芙尔另有队友已用掉、偏借满命的限定，不能生成“二命即可独立处理后两幕”的规则。A 22:21–22:43的圣牌一讲解以那维莱特为选项，并说明替代阵容的治疗要求；不据条件句确认其实际选人。

B 02:13–02:49利用首幕敌人自带水的情境，提出卡维、久岐忍等组合，第二幕又按是否招到挂草角色分流。这里可提取“环境能提供部分反应条件”，但不能泛化成所有前期关卡可省水位。B的账号前提也不能被“做题公式”四字抹去。

D提供独立反例：其第八幕自述队伍为赛索斯、菲谢尔、莫娜、砂糖，并投入感电祝福；第十幕则留桑多涅和按治疗配置的多莉。四星既可能承担低压力输出，也可能是必须保留的功能位。这里有常驻五星和实际配置前提，不是纯四星低练通关证明。[D 17:48–19:36、21:25–22:40；详见YouTube报告]

## 祝福不能只保存“感电4级”

A 03:29、07:02倾向感电2级左、4级左；B 02:03–02:13倾向2级右、4级右，并在04:39–04:47解释后者能治疗前台。这两条路线不能取平均或投票合成统一答案。

E的现有条文解释了差异可能来自哪里：感电的浮雷路径偏额外攻击，雳云路径包含回能或前台治疗，其末级分支又分别固定为落雷或暴雨。**治疗不是给伤害统一乘倍率，也不等于全队治疗。** 因此B所述前台回血不能自动证明它能解除全队伤害贡献者身上的机制减益。A 25:55–26:10反而强调相关队员都需恢复，字幕误写“来买”的地方高度疑为“奶满”。

左右位置与正式路径的对应仍需按当期准确选项核对；本报告只确认作者的口述方向与社区条文所示功能差异，没有实测治疗量能否满足特定角色需要。E还分别记载绽放增幅、额外草原核、激化额外伤害及减抗等效果，因此“反应名+总等级”无法完整代表能力变化。

C 01:58–02:43的通用观点与D 05:31–06:58的当前期复盘，都区分祝福自身伤害和对已有输出的放大。它们支持比较收益类别，但不能推导所有低练队都应选择同一分支。

## 文字提取和别名处理的教训

[术语审计](transcript-alias-audit-2026-09-18.md)保留原词、规范名称候选、时码、来源与置信度。鸡哥、火螃蟹、少女、牛牛等可依语境检索核对；“龙蜥”“小宝”等仍须保留具体敌人及变体，不能做全局字符串替换。

完整字幕已纠正三类摘要失真：借角前提丢失、幕次混合、把“治疗到满血”改写成配装暴击建议。B 00:30–00:34的断句经用户本次校对，采用“剩下全选感电，激化 Buff 不需要碰”，撤回摘要的“感电和激化都选”。结合00:27的一级绽放建议，B的路线应记录为：一级绽放，其余选感电，不投入激化；后续感电二级、四级选右。这是该作者在其账号及预留前提下的当期路线，不是所有队伍禁用激化的规则。校对来源是用户反馈，未重新观看视频或改写原始SRT。

YouTube已用环境现有yt-dlp提取D的`en-orig`自动字幕，没有下载视频或运行新的语音识别。另两条高相关候选未列出字幕，说明渠道更方便仍不等于每条都有。当前可复用流程是：枚举字幕 → 下载原字幕及时间戳 → 校对名称和否定条件 → 提炼带前提的案例。没有字幕时才另选第三方转录，摘要用于导航而非代替原文。具体命令与失败记录见[YouTube报告](youtube-theater-evidence-2026-09-18.md)。

## 给能力描述决策的事实输入

下表是研究归纳，产品字段与呈现仍待人类决策票确认；沿用用户“先假设信息齐全”的范围，不新增缺信息交互。

| 应保留的条件 | 本轮证据说明的用途 |
|---|---|
| 当前目标、敌人及精确变体 | 作者追求满星的65秒不能自动变成巡演原石的基础可行性门槛；见[奖励规则报告](https://github.com/HaotongCheng/BetterTheater/blob/57aa5f59b871f3ba56a54243c860dd0746573233/docs/research/theater-rules-resolution-2026-09-17.md) |
| 当前组合、可替代职责、配装与基本操作 | 持续挂元素、武器循环、前后台位置、治疗对象会改变“能不能承担任务” |
| 已有祝福的正式分支、触发、收益对象 | 与理想计划分开；看下一次升级新增什么，而非只评价终态4级 |
| 实际入队、可用耐力、花朵及当前候选 | 判断现在补人、升祝福或保留资源；作者建议不能代替实际执行事实 |
| 后续需要保留的任务与可替代路径 | 允许强角色提前上场，也允许四星因机制价值被留到后面 |
| 来源、期次、前提、结果性质 | 区分作者推荐、自述成功、机制条文与研究推断，保留作者分歧 |

建议能力条目的含义可表达为：“在这些条件下，这组角色能承担此任务；需要这样操作；现在使用会消耗哪些后续选项。”这只是待讨论的描述方式，未选择评分器或做产品实现。

仍缺的证据：完整连续状态账本、与用户练度一致的重复验证、低命和低练的数值门槛、作者分歧的受控比较。后续验证应针对具体推荐收集这些证据，而不是把未证实阈值先写成规则。当前研究结论不支持硬性禁选、不支持“玩家跳过一次就长期排除角色”，也不改变每次结算和开战前重新读取真实状态的已确认要求。
