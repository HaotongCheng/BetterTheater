# 剧诗攻略中的条件决策：首轮证据调查

研究日期：2026-09-17。对应 [issue #3](https://github.com/HaotongCheng/BetterTheater/issues/3)。本报告提取攻略作者如何解释建议，不验证其游戏机制数值，也不选择推荐算法。

## 结论与证据边界

首轮证据足以否定“把攻略逐幕角色名单照搬到任意账号”的做法：作者自己的建议已经按持有角色、能借的角色、后续机制、当前入队结果以及操作把握分支。它不足以量化命座或武器的价值，更不足以证明完整队伍总比主力加挂件好。

以下 A、B 是已打开并完整核对正文的作者原帖；C、D 为作者原帖的搜索索引可读内容，直接打开仅返回 Loading，不能称作全文核验。它们只补充候选假设，不承担当前版本规则证明。所有访问均为上述研究日期；没有观看或转录视频。A、B 同属一位作者，因此不是独立共识。

## 可核查案例

### A：先补机制能力，再借高配输出；预留和祝福随账号改变

来源：冻梨游研社，[V5.3／2025-02-01／火水风期](https://www.taptap.cn/moment/634811478452473299)，正文“一、战前准备”“二、战中技巧”。

**作者明确说的：**若没有克洛琳德或恰斯卡，助演优先恰斯卡，以应对第八幕护罩；已具备该能力则可借其他高练输出。风系主力对应补珐露珊等搭档。祝福起步方向按自有主力元素分布改变；担心入队随机性时预留行秋，并提前取得和留住后关核心。

**研究者推断：**借角是在补账号缺口，不是照一张强度榜取第一；“替代”必须保留任务能力，不能仅匹配元素。

**适用前提和缺失状态：**该期攻略，不能沿用到新敌人；未提供完整账号、命座武器表、实际入队轨迹、货币、已买祝福或失败次数。“高练高配”无数值门槛。对操作熟练者提供的躲伤替代不等同于低重试建议。

### B：从末关倒推，但核心未入队时必须改计划

来源：冻梨游研社，[V5.8／2025-09-01／火水草期](https://www.taptap.cn/moment/711604668622440650)，正文“一、初期准备”“二、BOSS策略”“四、结尾”。

**作者明确说的：**不持有基尼奇且不熟悉机制时，建议借高命高练基尼奇。祝福在蒸发、燃烧之间按最终阵容选择；从开局预留末关所需角色。第六幕目标角色没入队时，从现有可实现方案选：特定角色破盾、燃烧配高频攻击，或最后考虑躲爆炸。第八幕治疗能承担机制任务。

**研究者推断：**初始规划应记录预留理由与替代方案；治疗、挂元素和攻击频率都是组队贡献，不能把非主输出统称可随意替换的挂件。

**适用前提和缺失状态：**借用建议显式依赖命座和熟练度，但缺武器、天赋、圣遗物与输出阈值。正文也谈星章时限，不能原样套到本项目“原石优先”目标。攻略角色举例仍需另查当期准入，不能充当合法性清单。

### C：招募优先的理由有条件，不能提升为全局定律

来源：DreamBoattt，[V4.8／2024-08-02／困难模式](https://www.hoyolab.com/article/31703933)，搜索索引可读“关卡事件说明”“角色培养说明”；全文未核验。

**作者明确说的（索引）：**先让角色够用再取增益，余花可增加可出战角色；随机收获不一定符合需求。作者认为当期部分关卡一两名充分培养的角色可带等级达标的其余人。

**研究者推断：**“招募优先”隐含当前可用组合不足；“挂件足够”隐含核心已能过关。无法据此推出低练账号也可忽略协同。

**缺失：**无可核对的完整账号和逐次选择记录，尤其缺花费、候选事件、可出战角色及剩余耐力；这是旧规则期经验，不是现期推荐顺序。

### D：固定攻略可能主动要求重开，与本项目目标不同

来源：Clorinda.TW，[V5.8／2025-09-01／卓越满星](https://www.hoyolab.com/article/40841528)，搜索索引可读第一、二幕；全文未核验。

**作者明确说的（索引）：**第一幕先将燃烧祝福升至指定等级，没达到则重开，之后招募；第二幕使用胡桃、托马及任意两角色，并提醒水角色可不上场。

**研究者推断：**不能把“补完整队伍”理解成四人都必须上场；元素干扰可能破坏既定策略。该开局策略也说明，照抄满星攻略可能引入用户不愿承担的重试。

**缺失：**未核验后续全程、账号配置、重开频率和费用。不能证明该策略比招募优先更好；与 C 不构成受控比较。

用户给出的前两张一图流缩略图无法可靠辨认，不提取逐幕角色。第三张评论可读：作者显示名为“提瓦特高级特工穿山甲”，说明把“少女”留到后面需多准备副 C，试用角色不能独立承担原安排，需要按副 C 强度决定第七或第八幕使用。此处仅概述，没有确认原视频、期次、发布日期或完整账号，也没有把昵称换成实名。截图支持“同名角色／试用配置不能无条件替代”的问题，不能据此建立伤害阈值。原始材料保留在本次会话附件，临时文件路径不是长期研究来源。

## 待验证的决策因素与反例

以下是研究者为 MVP 整理的状态需求，不是新的游戏规则。

| 因素 | 推荐需解释什么 | 应主动检验的反例 |
| --- | --- | --- |
| 目标与期次 | 为哪项奖励、哪一关保存能力 | 满星攻略要求重开，原石目标是否实际需要 |
| 自有、试用、实借角色 | 推荐为何适用于这个版本的角色配置 | 同角色低命或无专武不能照搬高配单带 |
| 组队协同 | 输出、生存、挂元素、破盾、循环的具体分工 | 凑齐四人却抢反应；保留主力却耗尽唯一机制辅助 |
| 已入队与待命 | 当前可实现什么、什么仍依赖后续随机 | 预定队友没来，固定逐幕表失效 |
| 剩余耐力和后关用途 | 现在使用会放弃哪个后续方案 | 为末关过度保存，当前关反而打不过 |
| 事件候选与货币 | 招募补哪个缺口，祝福改善哪支实际队伍 | 已有足够组合还盲目招募；先买不适配角色的祝福 |
| 操作经验与失败记录 | 建议的操作能否稳定执行 | 理论可躲伤，用户反复失误，需改生存方案 |

“强度”至少应带具体队伍、敌人、祝福和任务语境；本调查不支持单一全局角色分数或命座／五星武器二元阈值。账号数据能描述配置，但不能单独证明稳定通关能力。

## 对后续人工验证的最小输入

在一期实测中，逐次保留：目标与关卡、可出战及待命名单、实际配置和剩余耐力、现有祝福、货币及屏幕候选、选择理由、关键预留、未采用的替代方案。结束记录是否获得目标奖励、重试次数及原因，并注明哪些角色来自试用或借用。用户熟悉的队伍应独立记录，不从账号面板猜测。

需要补的证据是一个可回放的完整决策轨迹，以及不同账号条件下的反例。招募与祝福的定量取舍、命武差异导致的带队能力变化、当前月反应队伍组合和跨期泛化均未解决；本报告只完成 issue #3 的首轮因素与证据缺口调查。先对用户账号做人工建议验证，通过后再扩大测试群体；不因找到攻略就声称提升了通关率。
