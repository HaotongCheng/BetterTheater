## 已补齐的历史规则

以下均限定为 **2025-10 起公告描述的规则**，不自动宣称之后未改。

| 项目 | 核实结果 | 对规划的影响 |
|---|---|---|
| 月谕入场 | 曾通关卓越；至少 28 名角色，可多带 4 名；等级 70；可邀请 1 名助演角色。[A3、B5] | 检查参演资格和实际可借对象；不能只数自有角色总量 |
| 圣牌挑战出现 | 消耗一定耐力后出现，至多同时 2 个；公告未给精确触发阈值。[A2、B5] | 记录出现事实，不写死“第四幕同时出现”或某个耐力数值 |
| 挑战时机 | 官方配图明确在第十幕前挑战，可选择时机，进入前能看详细挑战信息。[A2] | 进入第十幕前检查尚未完成的圣牌挑战；不能把“随时”理解为第十幕后仍可补打 |
| 圣牌挑战失败 | 失败不消耗耐力，可以重复尝试，或返回事件选择等待更合适时机。[A2] | 不等同于整局回溯；也不据此推断其他全部资源和随机状态不变 |
| 强敌前事件 | 卓越与月谕中，若强敌有对应优势元素，强敌战前保证出现相应角色事件。[A4] | 与普通随机事件区分；不代表一定获得某个指定角色 |
| 三选一 | 卓越与月谕的强敌战后可选一名；月谕还扩展至圣牌挑战后和角色事件。[A4] | 候选数量取决于模式和节点，不能统一假定二选一或三选一 |
| 第一幕前祝福 | 全难度可以选择并升级多类辉彩祝福，或优先集中一类。[A4] | 局前计划要覆盖第一幕前资源取舍；这不是“任何选项永远可买”的保证 |

## 原石与星章必须分开

官方新增奖励图实际展示：[A3]

| 类别 | 档位 | 原石 | 条件与限制 |
|---|---|---:|---|
| 新增巡演奖励 | 圣牌挑战第一档 | 100 | 完成对应圣牌挑战，并通过第十幕 |
| 新增巡演奖励 | 圣牌挑战第二档 | 100 | 完成对应圣牌挑战，并通过第十幕 |
| 新增初演馈赠 | 第一档 | 150 | 首次对应完成记录；与周期奖励单独核对领取状态 |
| 新增初演馈赠 | 第二档 | 150 | 同上，不能每期重复算入 |
| 新增星章奖励 | 当期累计 12 星章 | 图示为祝圣之霜 | 这是材料奖励；该图没有把 12 星章列为上述新增原石的门槛 |

**可以确定的增量：巡演新增 200 原石，初演新增 300 原石。** 这张图是增量图，不是所有难度、全部幕次、全部星章档位的完整奖励表。它不能单独证明当前总数 1000，也不能据此断言所有版本的星章奖励都没有原石。完整“拿满”目标仍需奖励页全档位核对。

对现有地图目标的建模建议（不是官方规则）：把目标分成「本期巡演原石」与「账号尚未领取的初演原石」两栏，并逐档记录条件和领取状态。资格不足或只打到卓越时，应显示尚缺档位，不能改称拿满。

## 整局状态与决策清单的修订

本表是从证据推导的需求模型；字段和处理方式是研究建议，不是最终技术方案。

| 节点 | 需要的状态 | 决策及更新 |
|---|---|---|
| 确认期次和奖励目标 | 服务器、版本、期次、模式、奖励各档条件与领取状态 | 确定本局目标，区分原石与材料、周期与首通 |
| 选择参演与借角 | 自有角色池、参演资格、试用角色、实际可借角色、角色练度 | 形成参演名单与初始预留计划；不将拥有等同可参演 |
| 第一幕前资源安排 | 实际事件、价格、花朵、祝福类别与等级、当前可出战角色 | 选择集中升级或多类祝福，以及角色获取；读真实候选 |
| 幕间事件与招募 | 当前幕、可见事件及价格、待命与可出战角色、剩余耐力、已有助益 | 比较买角色、买祝福、其他事件、刷新或进入战斗；候选三选一只用于已核实节点 |
| 普通战与强敌战配队 | 关卡条件、敌人、星章条件、可用角色、后续已知需求 | 分配出战与预留；战后用实际结算更新耐力、花朵与角色 |
| 圣牌挑战 | 两场分别是否出现/完成、具体战斗条件、实际阵容 | 现在打、失败后重试、延后；在进入第十幕前检查遗漏 |
| 回溯与重开 | 返回位置、次数、角色/耐力、花朵、祝福、候选、挑战完成状态 | 根据恢复后的实际画面重建；不能复用“圣牌失败不耗耐力”来推断回溯语义 |
| 结算与领奖 | 幕次、圣牌完成、星章、全部奖励档位 | 逐档确认目标完成，记录重试及未完成原因 |

原报告的稳定概念、版本规则、每期配置、本局观察结果四层仍适用。这里再次强调：随机概率未知；角色事件的保证出现与具体候选抽取是两层机制；可见示例价格不是完整固定成本表。

## 尚需游戏内取证的最小清单

1. **奖励与准入**：所选服务器/期次/版本、各模式说明、巡演/初演/星章奖励页全部档位（已领取也可，须看清条件与原石数字）。先完成这一项，就能判断“拿满”到底包含哪些条件。
2. **一次整局过程**：第一幕前与各幕事件、角色候选、耐力、祝福、花朵；圣牌挑战的首次出现与完成；每个决定前后成对记录。完整事件全集不要求在一局刷齐，未见事件保持未知。
3. **一次回溯对照**：回溯提示、可回位置和次数、操作前后上述状态。失败重试与回溯分开记录；不要求为了测试刻意放弃奖励或消耗稀有资源。
4. **当期敌人与祝福文本**：至少覆盖该局会采用的选项和关卡；记录无法读清或未出现的部分。
